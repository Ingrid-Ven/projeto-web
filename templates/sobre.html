Sobre Vantagens Estrutura Exemplo

O que é Flask?

Flask é um microframework web escrito em Python. Ele é leve, simples e flexível, permitindo que desenvolvedores criem aplicações web rapidamente.

Diferente de frameworks mais robustos, o Flask oferece apenas o essencial, dando liberdade para o desenvolvedor escolher as bibliotecas que deseja utilizar.

Principais Vantagens

  • ✔ Fácil de aprender
  • ✔ Estrutura simples e organizada
  • ✔ Ideal para APIs REST
  • ✔ Alta flexibilidade
  • ✔ Grande comunidade

Estrutura Básica de um Projeto

Um projeto simples em Flask pode ter a seguinte estrutura:

/meu_projeto
│
├── app.py
├── templates/
│     └── index.html
└── static/
      └── style.css

O arquivo principal normalmente é o app.py, onde definimos as rotas e configurações da aplicação.

Exemplo de Aplicação Flask

Exemplo simples de código em Python:

from flask import Flask

app = Flask(__name__)

@app.route("/")
def home():
    return "Olá, mundo com Flask!"

if __name__ == "__main__":
    app.run(debug=True)
